桌面时钟 v1.1.0（Windows 64 位 · 绿色版）
================================================

一、运行
------------------------------------------------
双击 DesktopClockGo.exe 即可。无需安装、无需运行库、不写系统目录。
程序启动后只在托盘显示一个图标，不占任务栏。

注意：本程序为单实例运行。若已在运行，再次双击会弹出一个提示框，
      然后自动退出 —— 不会出现两个时钟。
      提示框里会告诉你到哪里找托盘图标（详见第八节）。

二、托盘菜单（右键托盘图标）
------------------------------------------------
  选择颜色...                    弹出系统取色器
  选择字体...                    弹出系统字体对话框
  不透明度（当前 85%）           子菜单：60% / 75% / 85% / 95% / 100%
                                 勾选的是当前值，点一下立刻生效并写回 config.json
                                 （手改过 config.json、当前值不在这些档位里时，
                                   标题仍会显示实际数字，只是没有勾选项）
  ------------------------------
  12 小时制                      勾选=12 小时制，取消=24 小时制
  锁定(鼠标穿透)                 勾选后鼠标可直接点穿时钟，不再挡住下层窗口
  只在桌面显示(不遮挡窗口)       勾选=贴在壁纸上、被所有窗口盖住
                                 取消=变回传统置顶悬浮窗
  开机自启动                     写 HKCU\Software\Microsoft\Windows\
                                 CurrentVersion\Run，只影响当前用户
                                 （若之后把程序文件夹改名或移动，下次启动
                                 会自动把自启项改指到新位置，不用重新勾选）
  退出                           关闭程序

三、配置文件
------------------------------------------------
config.json 与 exe 同目录，纯文本，可直接编辑（改完需重启程序）：

  hour_format    "24" 或 "12"
  color          "#39FF14" 这样的十六进制颜色
  font_family    字体名，如 "JetBrains Mono SemiBold"
  font_size      字号，单位像素
  font_weight    "normal" 或 "bold"
  italic         true / false
  opacity        整体不透明度 1-100（100 = 完全不透明），默认 85
  x, y           窗口左上角坐标
  autostart      开机自启（启动时会以注册表实际状态为准）
  click_through  鼠标穿透
  desktop_layer  只在桌面显示

config.json 不存在时，程序启动会按默认值生成一份
（亮绿 #39FF14、Consolas 粗体 48px、不透明度 85、坐标 100,100）；
把它删掉再启动，就回到这套默认值。

注意：本压缩包内不含 config.json，解压后首次运行才生成 ——
这样不会把别人机器上的坐标、字体带过来。

升级到新版本时，只替换 DesktopClockGo.exe 就好（icon.ico、使用说明.txt 可一并替换），
不要把整个目录清空再重新解压 —— config.json 不在压缩包里，目录一清空，
你的颜色、字体、坐标、不透明度就全没了，程序会按上面的默认值重新生成一份。
这时候看到的现象是"时钟跑到左上角、颜色变回亮绿"，很容易误以为程序坏了。
稳妥做法：先把旧的 config.json 复制出来，解压完再放回去。

四、建议的测试清单
------------------------------------------------
[1] 12/24 小时制
    右键托盘 → 勾选"12 小时制" → 应显示"下午 02:08:33"这类格式，
    窗口会自动变宽；再取消勾选，恢复 24 小时制且窗口变回原宽。

[2] 颜色与字体
    右键托盘 → 选择颜色 → 选一个颜色 → 立即生效；
    选择字体 → 换字体/字号/斜体/粗体 → 立即生效。
    确认数字和文字的边缘干净，没有白边、描边或杂色。
    这一版起，文字边缘是柔和过渡（不再有硬锯齿），整幅默认带 85% 不透明度，
    能微微透出壁纸。想要更实/更淡：右键托盘 → 不透明度 → 选一档，立即生效；
    也可以直接改 config.json 里的 opacity（1-100），那种方式重启后才生效。

[3] 桌面层（核心需求）
    取消"锁定(鼠标穿透)"后，把任意窗口（浏览器/资源管理器）拖到时钟上方，
    时钟应被盖住、而不是浮在窗口上面。
    按 Win+D 显示桌面 → 时钟应仍在原位（约 1 秒内自动复位）。
    再勾回"锁定(鼠标穿透)"。

[4] 拖动与锁定
    先取消"锁定(鼠标穿透)"，按住时钟拖到别处 → 松开后位置生效；
    退出程序再启动 → 位置保持不变（已写入 config.json）。
    勾回"锁定(鼠标穿透)"后再点时钟 → 点击应穿透到下层，时钟不动。

[5] 开机自启
    勾选"开机自启动" → 注销或重启后应自动运行；
    取消勾选 → 注册表项被移除。
    额外检查：勾选后把整个程序文件夹改名，再启动一次程序，然后看
    注册表项 HKCU\...\Run\DesktopClock 是否已自动指向新路径
    （不检查这一条，改名后就只能等到开机才发现自启失效）。

[6] 退出
    右键托盘 → 退出 → 进程结束，无残留；托盘图标消失。

[7] 防重复启动
    在已有一个时钟运行时，再双击一次 exe
    → 应弹出"时钟已经在运行了"的提示，点确定后该进程自行退出，
      托盘里仍然只有一个图标、屏幕上仍然只有一个时钟。

五、已知的、符合预期的行为
------------------------------------------------
· 玩游戏（全屏独占）时看不到时钟 —— 因为它在所有窗口之下，这是设计如此。
  按 Win+D 或最小化游戏即可看到。
· Win+D / 右键"显示桌面"后，时钟会在约 1 秒内自动复位到桌面层。
· 首次运行会把配置写到 exe 同目录；若目录只读（如放在 Program Files），
  配置将无法保存，请放在普通用户目录下。
· 文字默认是半透明的（opacity = 85）。深色壁纸上如果觉得偏淡，右键托盘 →
  不透明度 → 选 95% 或 100%；浅色壁纸上嫌抢眼就选 60% / 75%。
· 时钟的窗口是"整块矩形"接收鼠标的（透明处也算）。默认开着"锁定(鼠标穿透)"，
  所以点哪儿都直接穿过；只有取消锁定准备拖动时，点到数字周围的空白也会开始拖。

六、卸载
------------------------------------------------
退出程序 → 删除整个文件夹即可。
如果开过自启，请先在托盘取消勾选，或手动删除注册表项
HKCU\Software\Microsoft\Windows\CurrentVersion\Run 下的 DesktopClock。

七、技术信息
------------------------------------------------
纯 Go 实现，直接调用 Win32 API，零第三方依赖，CGO_ENABLED=0 静态编译。
文件大小约 2.9 MB，内存占用约 16 MB，启动约 50 ms。

· 关于"64 位"与"Win32"：本程序是 64 位程序（PE 头 Machine = 0x8664，
  PE32+ 格式），调用的却是 Win32 API —— 后者是 Windows 原生接口家族的
  名字，64 位程序沿用同一套（user32.dll / gdi32.dll 里的 "32" 是
  16→32 位年代的遗留命名），与程序位数无关。

八、为什么任务栏上找不到它
------------------------------------------------
1) 没有任务栏按钮：程序窗口带 TOOLWINDOW 扩展样式，不占任务栏、
   也不进 Alt+Tab —— 桌面挂件的本意是像壁纸的一部分，而不是一个"应用"。
   要操作它，请用托盘图标的右键菜单。

2) 托盘里也看不到图标：Windows 11 默认把新程序的图标折叠进溢出区。
   图标显示与否完全由你在系统设置里决定，程序不会代劳：
     设置 > 个性化 > 任务栏 > 其他系统托盘图标
   在列表里找到"桌面时钟"（图标是一个青色表盘），把开关打开即可。

   反过来，你把它关掉，它就会一直保持关闭 —— 程序不会在重启后把它
   改回来，也不会替你打开。关掉图标后右键菜单进不去，想退出程序请用
   任务管理器结束 DesktopClockGo.exe；想找回菜单，回这个设置里打开即可。

3) 万一列表里也没有、任务栏上连"^"折叠按钮都不出现：这是资源管理器的
   托盘状态卡住了（此时任何程序新加的托盘图标都不会显示）。重启资源管理器
   即可恢复：
     任务管理器（Ctrl+Shift+Esc）→ "Windows 资源管理器" → 右键"重新启动"
   从这一版起，程序会监听系统的"任务栏已重建"通知，资源管理器重启后会自动
   把图标挂回去，不需要你再去重启时钟本身。

九、托盘设置里出现两个「桌面时钟」怎么办
------------------------------------------------
原因：Windows 把托盘图标的显示设置**按 exe 的完整路径**分别记录。
所以同一个程序在不同文件夹各运行过一次，就会各留一条记录；
文件夹删掉之后，那条记录仍然留着，不会自己消失。

处理办法：
1) 只保留一份程序，固定放在一个目录（例如 Documents\DesktopClock），
   其余解压出来的副本目录删掉。
2) 从当前版本起，程序每次启动会自动做两件事：
   · 清掉「exe 文件已经不在了」的旧记录（这类死记录不会再累积）；
   · 若发现还有另一个副本的文件仍在，会弹一个置顶提示，把路径列出来，
     你按提示删掉多余的目录即可。

注意：系统是按路径区分身份的，程序自己无法把两条记录合并成一条，
最终仍需你只保留一份程序。
